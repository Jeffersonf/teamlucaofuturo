# Diretriz de Design System: Team Lucão (Sports Red Edition)

Quando solicitado para alterar, criar ou refatorar interfaces (HTML/CSS/JS):
1. Seguir rigorosamente o padrão **Shadcn / Linear / Sports Red**.
2. Paleta Dark: Base `#09090b` (zinc-950), superfícies `#18181b` (zinc-900), bordas `1px solid rgba(255,255,255,0.08)`.
3. Destaque: Vermelho Esportivo `#dc2626` (red-600) com hover `#ef4444`.
4. Tipografia: `Plus Jakarta Sans` ou `Inter`.
5. Ícones: Lucide SVGs monocromáticos. NUNCA usar emojis em botões ou tags.
6. Micro-indicadores: Pontinho sutil de 6px para status (verde esmeralda ou vermelho suave).
